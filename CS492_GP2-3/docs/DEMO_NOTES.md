# Sprint 1 Demo Notes and Feedback Log

## Suggested demonstration
1. Launch the project with `run.bat`.
2. Attempt an incorrect administrator password and show the generic error.
3. Sign in using the demo administrator account.
4. Register a student and show the record on the student list/dashboard.
5. Attempt to reuse the same student ID and show duplicate prevention.
6. Register a teacher and show the linked user account.
7. Sign out, sign in as the teacher, and demonstrate that administrator-only pages are blocked.
8. Run the automated tests.

## Review checklist
- Authentication succeeds only with valid credentials.
- Password values are represented by hashes in the database.
- Logout clears the session.
- Required fields are enforced.
- Duplicate identifiers are rejected.
- Teacher accounts receive the teacher role.
- Non-admin users cannot access student or teacher management.
